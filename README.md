# crm
توجه داشته باشید که ادمین از پنل جنگو تعریف شود.
امکان ثبت نام ادمین وجود ندارد.
یک ادمین تعریف میشود و ان ادمین میتواند مدیران فروش و فروشندگان را ثبت نام کند.
مدیران فروش نیز میتوانند فروشندگان رو اضافه کنند.

### front : react
### back : django

### about 
امکان تعریف lead  و deal حرکت در قیف فروش با تغییر استیج دیل ها
تعریف استیج ها به شکل دلخواه به گونه ای که قیف فروش بر حسب نیاز تیم فروش تعریف میشود
تحلیل قیف فروش با kpi های مختلف
تحلیل روند فروش فروشندگان و فروش ها
تحلیل استیج های قیف فروش با kpi های استیج
و ...
